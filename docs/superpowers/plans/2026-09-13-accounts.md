# 多账号登录与画廊隔离实施计划

目标：支持注册和多账号登录，普通账号只见自己的画廊，root可见全部，图片与HTML存储目录不变。

设计：账号密码使用Werkzeug密码哈希；服务端从登录会话取得账号身份，不接受客户端传来的归属或管理员角色。新增按账号与日期联合主键的手记和最新故事表，旧表保留并兼容回填给管理员；归档及后台任务增加归属列。配置按账号独立。独立HTML原有分享行为保留。

约束：仅在项目内修改；不提交、不部署、不操作真实账号；测试使用临时数据库、模拟AI及本地浏览器。不得变更PHOTO_DIR和OUTPUT_DIR。

- [ ] 账号基础：增加账号表、注册输入校验、密码哈希验证、会话身份与CSRF轮换；测试注册、重复/保留账号、错误密码和退出。
- [ ] 数据隔离：新增账号表结构并无损回填历史数据；手记、配置、结果、任务、私有图片读取按身份过滤；root画廊汇总。测试两个用户同日期同步/异步生成、越权读取/删除/保留图片、旧数据库重启以及文件不覆盖。
- [ ] 页面接入：登录页注册入口与注册表单、显示当前用户名、代理及Nginx页面路由、缓存版本更新；测试浏览器注册登录切换及后端完整回归。
- [ ] 完成前核验：逐项对照需求检查代码与测试结果，更新项目记忆和部署说明；Nginx若本机不可用如实记录。
